claude-view

A desktop app that opens a dedicated window for each Claude Code CLI session, mirrors its terminal character-by-character, and keeps a readable, costed record of everything the session did.

Interactive system diagram → Pan, zoom, search, three guided views, PNG/SVG export. The whole runtime in one picture. Architecture: HLD & LLD → All 14 Rust modules and 25 TypeScript files, 24 IPC commands, 8 HTTP routes, the WebSocket protocol, every on-disk format, eight runtime flows, and the measurements behind each constant. Domain glossary → Run vs type, turn, replay, baseline, hosted vs watched, and what "live" is allowed to mean.
